# Python Beginner Repository

## About

This repository contains beginner-level Python programs for learning and practicing basic programming concepts.

### `factorial.py`

The `factorial.py` file is intended to demonstrate the calculation of the factorial of a number.

The factorial of a non-negative integer \(n\), written as \(n!\), is the product of all positive integers from 1 to \(n\).

For example, mathematically:

- `5! = 5 × 4 × 3 × 2 × 1 = 120`
- `3! = 3 × 2 × 1 = 6`
- `0! = 1`

*Note: The examples above explain the mathematical concept and are not verified outputs from the program.*

## Requirements

- Python installed on your computer.
- The `factorial.py` file available in your local repository.

No additional library requirements are specified in this README.

## How to Run

1. Open a terminal or command prompt.
2. Navigate to the directory containing `factorial.py`.
3. Run the following command:

   ```bash
   python factorial.py
   ```

   If your system uses `python3` to run Python, use:

   ```bash
   python3 factorial.py
   ```

4. Follow any instructions displayed by the program, if applicable.
